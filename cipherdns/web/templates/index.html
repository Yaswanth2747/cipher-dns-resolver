Configuring System DNS for cipherDNS

                
            

            

                
To route all system traffic (including Google Chrome, Firefox, curl) through cipherDNS on Linux:

                
                
Option 1: Point systemd-resolved to cipherDNS (Recommended)

                
resolvectl dns enp2s0 127.0.0.1
resolvectl flush-caches


                
Option 2: Direct /etc/resolv.conf override

                
sudo bash -c 'echo "nameserver 127.0.0.1" > /etc/resolv.conf'


                
Testing from Terminal

                
dig @127.0.0.1 netflix.com
curl -v https://netflix.com


                
To Restore Original DNS

                
./scripts/restore_system_dns.sh
